# CampusCash

Student-first financial dashboard built with React, Vite, Express, and MongoDB.

## Run locally

```bash
npm install
cp .env.example .env
npm run dev
```

Frontend: http://localhost:5173
API: http://localhost:5000

MongoDB is optional for the demo UI; set `MONGODB_URI` to persist data. Configure `GEMINI_API_KEY` to enable live Gemini answers.
